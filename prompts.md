# Prompts para copiar

Úsalos junto con tu ficha (`ficha/ficha_en_vivo.md`): pega primero la ficha y después el prompt.

| Para | Prompt |
|---|---|
| Diagnosticar un dataset | «Te paso un archivo y su ficha. Antes de analizar, dime qué representa cada fila, cuántos faltantes hay por variable, si hay duplicados y qué valores te parecen raros.» |
| Escoger la familia | «Con esta ficha, ¿qué familia de machine learning aplica: supervisado, no supervisado o mixto? Justifícalo en tres frases y dime qué necesitaría para cambiar de familia.» |
| Pedir código que entienda | «Escríbeme el código en Python para Colab, con un comentario corto en cada paso. Guarda el 25 % de los datos para probar y compara con una alternativa simple.» |
| Interpretar grupos | «Te paso el perfil de cada grupo. Propón un nombre para cada uno, justifícalo con las variables y dime qué información me faltaría para confirmarlo.» |
| Codificar textos | «Usa este libro de códigos. Asigna un código a cada fragmento, justifícalo con palabras del fragmento y marca los casos en los que dudes.» |
| Revisar un resultado | «¿Qué no es concluyente en este resultado? ¿Qué explicación alternativa no descarté? ¿Con qué fuente lo contrastarías?» |
